# Cyber Saathi 🔐

Cyber Saathi is a cybersecurity awareness and learning platform I built to make online safety easier to understand and practice.

The platform is designed for students and everyday internet users who want to learn how to stay safer online without needing a technical background.

## What you can find on Cyber Saathi

* 📚 **Learn** — Simple lessons about common cybersecurity and privacy topics
* 🧠 **Quiz** — Interactive questions to test what you have learned
* 🛠️ **Tools** — Practical tools for learning and practicing safer online habits
* ℹ️ **About** — More information about the project

Topics covered include:

* Phishing
* Password security
* Social engineering
* Malware
* Privacy
* Safe browsing

## Why I built it

I started Cyber Saathi because cybersecurity can feel complicated when you are just beginning.

I wanted to create something that explains important concepts in simple language and gives learners a place to practice what they learn.

The project also grew from my interest in making cybersecurity awareness more accessible to students.
